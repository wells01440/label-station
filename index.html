Label Station Support

Label Station is a Mac menu bar app that prints labels from PDF forms to any printer in Printers & Scanners, and serves the same labels to AI clients over MCP. It is free.

Get help

Report a problem or ask a question in Label Station's issues on GitHub. Include your macOS version, your printer's name, and the steps that show the problem.

In the app, Help > Label Station Help opens the full guide.

Common questions

Which printers work? Any printer listed in System Settings > Printers & Scanners. Label Station prints a PDF at 100% scale on the template's page size.

The app says my printer does not list the page size. The template's page size is not one of the media sizes the printer reports. Load stock of that size, choose another template, or set the template's size in Edit Template > Format > Page.

A value says it does not fit. The value is wider or taller than its field. The label still prints, clipped. Shorten the value, or widen the field in Edit Template.

Which record files can I import? XFDF, JSON, and CSV. The field names in the file match the template's field names.

How do I connect an MCP client? Open Settings > MCP, choose Copy Configuration, and paste it into the client's MCP settings.

Can I use a form from Adobe Acrobat or Preview? Yes. File > Open… adds any PDF form to the Library.
